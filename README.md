### Требования и запуск

Нужны **Git**, редактор кода (например, VS Code) и браузер[cite: 9].

| Инструмент | Задача |
| :--- | :--- |
| Git | Скачать репозиторий и отправить правки[cite: 9] |
| VS Code | Редактировать файлы и разметку[cite: 9] |
| Браузер | Проверить отображение страницы[cite: 9] |

Команды для работы:

```bash
git clone https://github.com/https://github.com/EkaterinaK123/PR12_Kostrova.git
cd https://github.com/EkaterinaK123/PR12_Kostrova.git
git status
git add .
git commit -m "Добавлен README.md"
git push
```
